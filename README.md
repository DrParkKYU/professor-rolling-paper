# 🎓 교수님을 위한 디지털 롤링페이퍼 (Rolling Paper)

누구나 접속하여 감사의 메모를 남길 수 있는 공개형 디지털 롤링페이퍼 웹 애플리케이션입니다.

## 🛠️ 기술 스택 (Tech Stack)
- **Frontend**: HTML5, Modern CSS3 (파스텔 포스트잇 스타일), Vanilla JavaScript
- **Database & Backend**: [Supabase](https://supabase.com/) (PostgreSQL & Realtime)
- **Deployment**: [Vercel](https://vercel.com/)
- **Version Control**: [GitHub](https://github.com/)
- **Libraries**: `@supabase/supabase-js`, `canvas-confetti`

---

## 🚀 빠른 시작 가이드 (Quick Start)

### 1. Supabase 데이터베이스 생성 (SQL Editor)
Supabase 대시보드의 **SQL Editor**에서 `supabase_setup.sql`의 내용을 실행합니다.

```sql
CREATE TABLE public.memos (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    author TEXT NOT NULL,
    relationship TEXT,
    content TEXT NOT NULL,
    color TEXT DEFAULT 'yellow',
    emoji TEXT DEFAULT '🎓'
);

ALTER TABLE public.memos ENABLE ROW LEVEL SECURITY;

CREATE POLICY "누구나_메모_읽기_가능" 
ON public.memos 
FOR SELECT 
TO public 
USING (true);

CREATE POLICY "누구나_메모_작성_가능" 
ON public.memos 
FOR INSERT 
TO public 
WITH CHECK (true);
```

### 2. API 키 연동
`app.js` 파일의 상단에 본인의 Supabase Project URL과 Anon API Key를 입력합니다:
```javascript
const SUPABASE_URL = 'https://본인의프로젝트아이디.supabase.co';
const SUPABASE_ANON_KEY = '본인의-anon-public-key';
```

### 3. Vercel 배포
GitHub 저장소와 연동 후 클릭 한 번으로 배포됩니다.
